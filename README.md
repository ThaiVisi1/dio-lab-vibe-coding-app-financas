
# 📄 PRD – Aplicativo de Finanças

## 1. Objetivo
Criar um aplicativo de finanças pessoais que permita ao usuário cadastrar receitas e despesas, visualizar saldo atual, aplicar filtros e gerar relatórios gráficos. O app deve ser simples, responsivo e amigável, com design moderno e armazenamento local dos dados.

---

## 2. Público-alvo
- Usuários que desejam controlar suas finanças pessoais de forma prática.  
- Pessoas sem experiência técnica avançada, que precisam de uma interface intuitiva.  
- Usuários que querem exportar dados para análise em Excel/Google Sheets.

---

## 3. Funcionalidades principais
- **Cadastro de transações:** Receitas e despesas com campos de valor, data, categoria e descrição.  
- **Visualização de saldo:** Exibição do saldo atual, total de receitas e despesas.  
- **Filtros:** Por intervalo de datas, categoria e texto.  
- **Gráficos:**  
  - Entradas vs saídas por mês (bar chart).  
  - Distribuição por categoria (doughnut chart).  
- **Exportação:** Botão para exportar transações em formato CSV.  
- **Armazenamento local:** Uso de `localStorage` para persistência dos dados.  
- **Interface responsiva:** Layout adaptado para desktop e mobile.  
- **Design moderno:** Uso de ícones (Font Awesome), cores suaves e tipografia clara.

---

## 4. Requisitos técnicos
- **Frontend:** HTML5, CSS3, JavaScript.  
- **Bibliotecas:**  
  - Chart.js para gráficos.  
  - Font Awesome para ícones.  
- **Armazenamento:** `localStorage` do navegador.  
- **Compatibilidade:** Navegadores modernos (Chrome, Edge, Firefox, Safari).  
- **Responsividade:** CSS Grid e media queries para adaptação em diferentes telas.

---

## 5. Extensões futuras (opcionais)
- Importação de CSV.  
- Definição de metas mensais e alertas de orçamento.  
- Modo escuro.  
- Integração com APIs de bancos ou planilhas online.  
- Versão mobile nativa (React Native ou Ionic).
